📌 Project Name

PET NEST - Pet Adoption Platform

🎯 Purpose

PET NEST is a modern pet adoption platform where users can browse pets, add new pets, submit adoption requests, and manage adoption activities easily.

It is built using Next.js, React, and MongoDB to provide a full-stack web application experience with smooth UI and performance.
